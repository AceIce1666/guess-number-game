# 猜数字小游戏

> 一个用 Python 编写的命令行小游戏：电脑随机想一个 1~100 的整数，玩家不断猜测，程序给出"大了""小了"的提示，直到猜中并统计猜测次数。

## 📖 游戏玩法

1. 运行程序后，电脑会在 1~100 之间随机想一个整数（不会告诉你）。
2. 你输入一个数字进行猜测。
3. 程序会提示：
   - **大了！再试一次。** —— 你猜的数字比答案大
   - **小了！再试一次。** —— 你猜的数字比答案小
   - **恭喜你，猜中了！** —— 猜中后游戏结束，并显示你一共猜了几次。

💡 **小技巧**：每次都猜当前范围的中间数（二分查找法），最多 7 次就能猜中哦！

## ✨ 功能特性

- 🎲 使用 `random.randint(1, 100)` 随机生成目标数字
- 🔍 "大了""小了"实时提示，帮助你缩小范围
- 🔢 自动统计猜测次数
- 🛡️ 输入校验：输入非数字或超出 1~100 会友好提示，且不计入猜测次数

## 🚀 运行方法

1. 确保电脑已安装 Python 3（推荐 3.8 及以上版本）。
2. 打开终端（cmd / PowerShell），进入本文件夹。
3. 运行以下命令：

   ```bash
   python 猜数字小游戏.py
   ```

也可以直接双击 `猜数字小游戏.py` 运行（需系统已关联 Python）。

## 🔑 核心代码解析

| 知识点 | 作用 |
| ------ | ---- |
| `import random` | 导入随机数模块 |
| `random.randint(1, 100)` | 生成 1~100 的随机整数作为答案 |
| `while True` 循环 | 让玩家反复猜测，直到猜中 |
| `if / elif / else` | 判断大了、小了还是猜中 |
| `input()` | 获取玩家输入 |
| `count += 1` | 统计有效猜测次数 |
| `break` | 猜中后跳出循环，结束游戏 |
